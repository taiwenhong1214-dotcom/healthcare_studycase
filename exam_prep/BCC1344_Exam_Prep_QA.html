SECTION A — Chapter 1: Introduction to Data Science

A1. (a) Differentiate between data and data science. (b) Data science is formed by combining three fields. Name and explain each field using a student performance analysis example. [2 + 6 = 8]
(a) Data is raw facts and figures (numbers, text, records) collected from a source, e.g. students' marks. Data science is the process of using statistics, programming and domain knowledge to turn that data into insights that answer a question or support a decision. Big data = a large combination of data from many sources.
(b)
  1. Statistics – to understand the data. E.g. calculate the average mark, pass rate and performance trend.
  2. Computer Science – to process the data using code/tools. E.g. write Python code or build a Power BI dashboard of results.
  3. Domain Knowledge – to understand the real problem. E.g. know what counts as a good or bad result in education (e.g. below 50 = fail, CGPA 3.5 = dean's list).
Combining all three = doing data science.
A2. Explain the difference between a population and a sample. Give one example of each and state one limitation of using a sample. [5]
Population: the entire group of interest. Example: all used-car owners in the United States.
Sample: a smaller subset chosen to represent the population. Example: used-car owners in Chattanooga, Tennessee.
We use samples because collecting data from the whole population is costly and slow.
Limitation: a sample will not be 100% accurate; if it is not representative (e.g. one city only), results can be biased and may not generalise to the population.
A3. Describe the three main stages of the data science lifecycle. [6]
The lifecycle starts with a question/problem to investigate (what are we trying to solve?), then:
  1. Data Preparation – collecting, cleaning, transforming, integrating and managing data so it is structured for analysis, storytelling and decision making.
  2. Data Analysis – examining the prepared data to uncover valuable insights and guide decisions (descriptive, diagnostic, predictive, prescriptive).
  3. Data Storytelling – communicating the insights through summaries, visualisations and narratives so the audience can understand and act.

D11. Differentiate the following pairs of terms with an example: (a) grouping vs aggregation (b) categorising vs binning (c) encoding vs normalising. [6]
(a) Grouping puts similar rows together by a category (group sales by month); aggregation combines values into a summary result (total/average/count of each group). Usually used together: groupby("month")["sales"].sum().
(b) Categorising assigns labels using a rule (score ≥ 50 → Pass, else Fail); binning groups continuous values into ranges (age 18–25 Young, 26–40 Adult) using pd.cut().
(c) Encoding converts text categories to numbers so computers/ML models can use them (Male→0, Female→1, or get_dummies); normalising rescales numeric values to a similar range, e.g. 0–1, so they can be compared fairly.
D12. State three common mistakes in data transformation and how to avoid them. [3]
(1) Overwriting original data → work on a copy df_clean = df.copy(). (2) Wrong data type (numbers stored as text, cannot calculate) → check df.dtypes, convert with astype/pd.to_numeric. (3) Incorrect grouping (wrong column or inconsistent labels "cs" vs "CS") → standardise text first, e.g. str.upper(), then group.

Definitions to memorise word-for-word

  • Data storytelling: communicating insights through summaries, visualisations and narratives.
